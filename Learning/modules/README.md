# Learning Modules

Modules are the structured study units of **The Curious Engineer**.

Each module connects:

```text
Reading
  +
Documentation
  +
Labs
  +
Project
  +
Reflection
```

---

# Module Structure

Create a module when it becomes active rather than creating a large tree of empty directories in advance.

```text
modules/
├── README.md
├── 01-linux/
├── 02-networking/
├── 03-git-shell/
└── ...
```

---

# Every Module Should Answer

- What am I learning?
- Why does it matter for DevOps?
- Why does it matter for observability?
- What should I be able to explain?
- What can I demonstrate?
- What failure can I reproduce?
- What evidence proves the learning?
- What is still unclear?

---

# Definition of Done

A module is not complete because the reading is finished.

Use evidence such as:

```text
Concepts understood
+
Lab completed
+
Failure reproduced
+
Troubleshooting documented
+
Implementation committed
+
Reflection written
```
