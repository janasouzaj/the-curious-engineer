# Completion Evidence

A module should not move to `Complete` only because reading is finished.

A stronger completion signal is:

- concepts explained in my own words
- lab completed
- failure intentionally reproduced
- troubleshooting documented
- references collected
- implementation or configuration committed
- short self-assessment completed

---

# Quarterly Review

Every three months, review:

- What can I explain without searching?
- What can I troubleshoot without a tutorial?
- Which mistakes taught me the most?
- Which topics still feel mechanical?
- What evidence exists in the repository?
- What should change in the roadmap?
