# Guiding Principle

Whenever possible, prioritize learning in this order:

1. Books
2. Official Documentation
3. Engineering Blogs
4. Conference Talks
5. Podcasts
6. Hands-on Labs
7. Building Real Projects

Tools change.
Fundamentals don't.
