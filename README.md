# The Curious Engineer

This repository is where I document my journey becoming an engineer, I'm not interested in learning tools just for the sake of using them, I want to understand the ideas behind them, experiment, break things, fix them, and document everything that teaches me something along the way.

The goal is simple: turn learning into real projects and share the process.

---

## What you'll find here

This repository is a collection of everything I'm building throughout that journey:

* Hands-on labs
* Technical documentation
* DevOps studies
* Kubernetes
* Observability
* Cloud
* Linux
* LGTM Stack (Loki, Grafana, Tempo and Mimir)
* Infrastructure as Code
* CI/CD pipelines
* Automation
* Troubleshooting notes
* Experiments
* Personal notes I'll probably come back to months later

Not everything here will be perfect! Some projects will start small, others will be completely rebuilt, and a few will exist simply because I wanted to answer a question that came up while studying, and that's exactly the point.

---

## Why "The Curious Engineer"?

Because I believe curiosity is one of the most valuable skills we can have. Every problem has a reason behind it, every system has something new to teach, every challenge is an opportunity to understand things a little better than yesterday. Curiosity is what keeps me moving, it's the key.

---

## My approach

I never like memorizing commands, I prefer understanding why they exist, how and when to use it. I don't like copying solutions without knowing what they're actually doing. I'd rather break an entire lab, learn from it, and rebuild it with confidence, that's the way how I learn.
